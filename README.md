# Pankaj Kumar — AI Engineer Portfolio

A responsive, multi-page static portfolio for AI/ML engineering, Generative AI, RAG, agentic AI, computer vision and data analytics.

## Run locally
Open `index.html` in a browser, or run:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

## Deploy to GitHub Pages
1. Upload the contents of this folder to the root of your repository.
2. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
3. Keep `index.html` and `.nojekyll` at the repository root.

This is a static HTML/CSS/JavaScript site; no build step or server-side runtime is required. GitHub's documentation: https://docs.github.com/en/pages/quickstart

## Included
- Home, About, Experience, Projects, Certifications, Achievements and Contact pages
- Responsive layout, animated reveal effects and interactive workflow visualization
